# PDF Compliance Checklist — DataSpark Project #64

## Six mandatory requirements
- [x] Interactive Terminal Interface: `main.py` provides a menu-driven command prompt.
- [x] Defensive Input Validation: centralized validation, blank checks, numeric bounds, valid dates and categories.
- [x] Core Business Logic Engine: item total = quantity × unit price; daily and category aggregation.
- [x] Local Data Persistence: structured CSV and JSON reading/writing with fallback loading.
- [x] Record Query & Search: keyword, category and date-range filtering.
- [x] Executive Summary: totals, averages, status indicators, category totals and daily trends.

## Stretch features
- [x] Markdown, TXT and CSV exports.
- [x] Daily spending threshold warnings.
- [x] Streamlit GUI.
- [x] Bulk CSV import with schema checks and row-level error reporting.
